# 제작자 표시

GitHub에서 `info-ui/common/creator-config.js` 파일의 `name: "[이름]"` 값을 원하는 이름으로 변경합니다. `year`는 표시 연도입니다. 메인과 네 모듈의 공통 shell에서 같은 설정을 읽습니다. 학교명은 표시하지 않습니다.

수업 모듈은 자체 HTML과 컨트롤러로 실행됩니다. 목차 바로가기는 원래 목차 버튼을, 방향키는 원래 다음/이전 버튼을 호출하므로 내부 단계와 역방향 복원 로직을 유지합니다. 모듈 전환은 부모 shell의 iframe을 교체하며 주소창은 유지합니다.

전체화면은 부모 UI shell 전체를 대상으로 요청합니다. 브라우저가 네이티브 전체화면을 지원하지 않거나 요청을 거부하면 창 안에서 목차를 숨기고 수업 영역을 확대하는 대체 모드로 전환합니다. 네이티브 전체화면이 허용될 때에는 브라우저 API를 사용합니다.
