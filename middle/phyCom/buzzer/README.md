# 수동버저 수업자료

## 구성
1. 개념·동작 원리·핀 역할
2. VCC → 5V, GND → GND, IN → D3 회로 연결
3. 도·미·솔 반복 연주
4. 교과서 77페이지 생일축하노래 코드·악보·연주
5. 나만의 노래 만들기

→ / > : 다음 단계, ← / < : 이전 단계. 이전 페이지로 돌아가면 최종 상태를 복원합니다.
팝업은 ×, 배경 클릭, Esc로 닫으며 소리와 음표 강조를 함께 정지합니다.
브라우저가 소리 자동 재생을 막으면 팝업의 소리 재생 버튼을 누릅니다.

## 근거와 재사용
- 2022 피지컬 컴퓨팅 교과서 인쇄면 75~77페이지(PDF 76~78페이지).
- 77페이지의 연주 블록 25개: 음·옥타브·시간을 시각적으로 대조해 전사했습니다. 총 25초입니다.
- 두 라#(시♭), 5옥타브 도, 0.75·0.25·1·2초를 원문대로 사용합니다.
- 같은 데이터로 코드·주파수·악보·강조 시간을 생성합니다. 악보는 제공 교과서의 악보·코드에 맞춘 SVG입니다.
- 시작/스페이스키의 모양 변경 및 말하기 코드도 단계별로 제시합니다.
- 공통 slides.css의 엔트리 블록·탭·설명 화면 스타일을 재사용합니다.
- circuit.js는 공통 회로 라우팅 구현을 재사용한 버저 전용 사본입니다. 실제 buzzer.png의 핀 좌표와 라벨만 변경했습니다. 공통 파일을 수정하지 않습니다.
- 모듈·오렌지보드·탭 이미지는 기존 ../assets 파일을 사용합니다.

## 직접 검증
- 두 JavaScript 파일 구문 검사 통과.
- 모의 DOM/AudioContext 검사: 개념 팝업 순서, 회로 3단계, 정·역방향 최종 상태 복원, 연주 블록 25개, 25초 데이터, 두 곡의 주파수 예약, 팝업 닫기·페이지 이동 시 음원/강조 종료 통과.
- GitHub 원본 버저 이미지를 실제 브라우저에서 확인해 핀 끝 좌표를 측정했습니다.
- 브랜치 수업 화면의 실제 브라우저 레이아웃·실제 청음·악보 강조 동기화는 미검증입니다. main 병합 및 Pages 배포는 수행하지 않습니다.
